# 历史反例与回归

这里是对本地修订材料所见问题的脱敏归纳，不转载未发表稿件，不凭日期、文件名或导师批注推断正文作者。已明确AI产生的文本可标为AI候选；归属未核的旧稿只标旧候选。作者提供或认可的稿件单列，不能因与旧稿相似就当成负例。

| 可见问题 | 为什么降低结论质量 | 下次生成应观察的行为 |
|---|---|---|
| 将所有场量、算子、递推阶次和约束接成开头长清单 | 方法细节挤占研究回答，读者不知何种认识发生改变 | 选使贡献成立的关键改变，并交代它带来的能力 |
| 按每张图重报采样、端点、残差和内部标签 | 数值表被搬进结论，多个段落没有独立科学职责 | 保留代表反差、控制关系和范围，不顺次复述图表 |
| 以“理论统一、系统全面、意义重大”重复收尾 | 同义评价没有增加结论 | 让具体认识或适用范围完成收束 |
| 三重理论条件在多个段落重复展开 | 论证被重复前提分割 | 首次说清必要条件或准确回引，后文按相同范围写 |
| 删除所有限制以追求流畅 | 局部有效被改成全域保证 | 保留影响真值的条件、例外和失效 |
| 把旧版本的某组误差或阶次当模板 | 模型和图件变化后数值已失效 | 当轮回读证据，旧数值仅作历史记录 |
| 将场恢复称为独立预测、将谱吻合称为全场验证 | 证据角色被扩大 | 区分条件重构、预测及观测量 |
| 在结尾承诺瞬态、器件或新结构应用 | 未完成工作被包装成已支持意义 | 仅保留能从本文推出的用途；展望明确未完成 |
| 把双语同步、唯一源、编译和交付状态写入结论 | 生产记录替代科研内容 | 这些记录保留在论文外 |
| 用更短的技术索引代替长清单 | 字数降低，信息层级没有改善 | 按物理问题重组，不以压缩率或缩写数验收 |

用户明确表示旧AI稿需要作为避雷材料，这不等于所有旧版本均已核实为AI。检查结果必须同时记录版本边界、作者归属和例外。

摘要的250词上限、摘要“不引用/少缩写”等偏好不自动成为结论规则。结论可能需要理论名称、准确回引或已有文献比较；是否保留取决于其科学任务。
