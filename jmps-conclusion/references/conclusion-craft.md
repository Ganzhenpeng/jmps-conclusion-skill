# 从发现到结论

## 信息层级

结论回答研究问题，不逐节重播正文。先找能改变读者判断的关系：以前只能预测什么，现在增加了什么能力；哪个变量控制哪个响应；哪个看似合理的替代指标失效；哪项结果在何种条件下保持。方法、验证和参数结果围绕这些关系安排。不同论文不必同时拥有这几类贡献。

如果开头已经交代对象和方法，后文不必再次完整介绍几何、所有场变量、递推阶数和求解器。保留区别于已有方法的操作及其作用即可。理论条件应在结论中以不改变真值的最小表述保留，或准确回指正文命题；不能从“在满足正则条件的局部邻域成立”压成“在任意状态精确成立”。

## 压缩的实质

| 原文承担的功能 | 处理依据 |
|---|---|
| 定义研究对象、关键方法 | 允许一次简洁交代，方法区别若支撑贡献则保留 |
| 逐项复述推导、求解和采样 | 移出结论，除非采样/求解本身是研究贡献 |
| 代表发现及可信对照 | 保留发现和比较对象，验证细节按解释所需选择 |
| 仅重复上一句的意义 | 合并或删除，不再追加泛化评价 |
| 决定结论的条件、失效、反例 | 就近保留，不当作冗词 |
| 与主线无直接关系的应用前景 | 删除或缩为具体、未完成的推论 |

不设置压缩百分比。短文可能省掉主贡献，长文也可能各段均有独立信息。第一次压缩重排信息层级，第二次才处理句内赘词。重要发现允许更长的句子和段落，次要不变关系可以短写。

## 语言判断

“结果充分说明本方法准确可靠，具有显著优势”没有给读者可判别信息。改写时要从输入找实际对象、基线、范围和新能力；找不到就删去评价，不编造一个数字。

“增加刚度反差扩大带隙”需核对保持哪些量、扩大的是绝对频宽还是相对变化、结论覆盖哪段参数范围。有混杂变量时只能保留实际观察。because/therefore/源于是因果承诺，不能只作句式连接。

英文用 establishes/derives 指实际建立的关系，用 shows/reveals 指输入支持的发现，用 is consistent with/may reflect 表示尚不能区分的解释。严格证明才能用 proves，不能把仿真曲线重合改成证明。词不是禁词，强度由证据决定。

中文避免名词堆叠和连续“实现了…揭示了…验证了…证明了…”排比；让因果、比较或条件承担连接。英文不以长名词串替代物理主语，不在缺少事实时用 novel/comprehensive/robust 提升语气。

## 原创演示：仅为虚构写作材料

输入事实：在所测三组参数的第二传播支，模型A相对参考解的频率误差低于1%；第一带隙内未检验；重构是在给定宏观位移下完成。

失真结论：本模型以低于1%的误差准确预测所有传播和衰减模态，并完成全场验证。

可用结论：模型A在所测三组参数的第二传播支上将频率误差保持在1%以内。给定宏观位移的重构进一步恢复了胞内变化，但其证据不构成带隙内的独立模态预测。

第二句的限制只有当稿件很可能混同两类证据时才需要出现在结论；如果范围在第一句已清楚且重构并非贡献，可以删掉整句。不要把演示变成每篇都需要的免责声明。

输入事实：改变参数r时绝对带宽由20增为22，基频由100降为50，所有数为虚构且同单位。

可用取舍：突出相对带宽变化主要受基频降低影响这一关系，比逐项报告四个端点再说“显著提升”更有信息；只有本文确实讨论该指标且分母定义支持时才能如此写。
